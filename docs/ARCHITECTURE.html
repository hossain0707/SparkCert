Security boundary: the local control server listens on loopback only. API calls require a per-process session token. Managed SSH tunnels bind only to localhost. Opt-in uploads go to a dedicated remote directory. Real SSH connections require a reachable network and independently verified host fingerprint.

Actual execution path

The system does not fabricate health scores or model evaluations.

  1. 1
    Register a connectionSave host IP or an SSH alias imported from OpenSSH configuration.
  2. 2
    Run safe diagnosticsCollect GPU/Linux/Docker state through predefined read-only SSH probes.
  3. 3
    Evaluate a reachable model endpointSubmit deterministic requests and record actual outputs and latency.
  4. 4
    Review and export evidenceSave scoped results locally and generate a PDF with methodology and limitations.
