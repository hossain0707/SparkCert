# Changelog

- Introduced local-first FastAPI backend, browser/optional desktop interface and SQLite evidence store.
- Added OpenSSH host profile management, alias import and system-terminal integration.
- Added read-only Linux/NVIDIA/Docker diagnostics, seven heuristic infrastructure checks and remote read-only directory listing.

- Added comprehensive cross-workspace handover, status/verification matrices, roadmap, motion design specification and interactive animated architecture reference.

**Release note:** This is not an official NVIDIA/compliance certification product, a hardware-validated installer set or a security-audited commercial production release. See `docs/PROJECT_STATUS.md`.
